# text-orientation-classifier

Определение ориентации текстового кропа: 0° или 180°.
Бинарная классификация, на выходе — вероятность `p_180`.

Метрика: Brier Score, `Score = 1 - Brier`.

## Данные

Два синтетических OCR-датасета: русский (`rus`) и английский (`eng`).
Из каждого взято по 50 000 изображений (`random.seed(42)`), плюс
5 000 из `eng_pro`. Итого 105 000 исходных изображений.



Ключевой момент: split делается **на уровне исходных изображений**,
до генерации пар. Для каждого исходника создаются два примера:

```
original      -> label 0
rotate(180°)  -> label 1
```

Если разделять после генерации пар, оригинал попадёт в train, а его
поворот — в val, и модель увидит один и тот же текст. Поэтому сначала
делим исходники, потом генерируем пары.

Итог:

```
train: 84 000 исходников -> 168 000 примеров
val:   21 000 исходников ->  42 000 примеров
```
## Источники данных

Русский и английский датасеты — синтетические генерации текста
от DonkeySmall, по структуре похожие: кропы с печатным текстом,
разные шрифты, размеры и фоны.

- Русский: [DonkeySmall/OCR-Cyrillic-Printed-1](https://huggingface.co/datasets/DonkeySmall/OCR-Cyrillic-Printed-1)
- Английский: [DonkeySmall/OCR-English-Printed-12](https://huggingface.co/datasets/DonkeySmall/OCR-English-Printed-12)
- Дополнительный английский (`eng_pro`): [IIIT-5K Word Dataset](https://cvit.iiit.ac.in/research/projects/cvit-projects/the-iiit-5k-word-dataset)

IIIT-5K — это реальные фотографии вывесок и сцен с текстом,
не синтетика. Он добавлен как небольшой домен-сдвиг в сторону
реальных изображений, ближе к тесту соревнования.

## Препроцессинг

Кропы имеют разное соотношение сторон (на тесте `width` от 25 до 1599).
`Resize((224, 224))` искажает текст, поэтому используется resize
с сохранением пропорций и белым padding до 224×224.

Далее `ToTensor()` и нормализация по статистикам ImageNet — те же,
на которых обучался backbone.

## Модель

MobileNetV3-Small (torchvision, веса ImageNet). Работает
на CPU. Финальный слой заменён на `Linear(1024, 1)` под бинарную
классификацию. Без заморозки слоёв.

Loss: `BCEWithLogitsLoss`. Optimizer: `AdamW(lr=1e-4)`. Batch 32,
CPU-only.

## Результаты на валидации

| Эпоха | Brier   | Score   | Accuracy |
|-------|---------|---------|----------|
| 1     | 0.05774 | 0.94226 | 92.09%   |
| 2     | 0.03448 | 0.96552 | 95.16%   |
| 4     | 0.02819 | 0.97181 | 96.19%   |

Лучший чекпоинт — `mobilenet_epoch4.pth` (выбран по Brier).

## Инференс

Тестовые изображения проходят тот же препроцессинг. Вероятность
получается через sigmoid от логита. Submission содержит колонки
`image_id,p_180`, где `image_id` — имя файла без расширения.

## Воспроизводимость

Загрузить готовый чекпоинт:

```python
model = mobilenet_v3_small(weights=None)
model.classifier[3] = nn.Linear(1024, 1)
model.load_state_dict(torch.load("mobilenet_epoch5.pth", map_location="cpu"))
model.eval()
```
